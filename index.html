客户充值统计工具

批量统计客户充值金额、充值笔数、充值明细，并导出 Excel 报表

官方下载

适用于 Windows 电脑。下载后双击即可运行。

下载最新版
当前版本：v1.0.0

功能介绍

  • 支持批量粘贴客户 ID
  • 自动统计客户充值总额和充值笔数
  • 支持只统计上个月流水
  • 支持排除退款记录
  • 自动导出 Excel 报表
  • 导出内容包含客户汇总、充值明细、未找到 ID
